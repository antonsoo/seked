# Contributing

Use Node.js 24 or newer and `npm ci`. Run `npm run check` and
`npm run verify:geometry` before proposing a change. For a change to controls,
source navigation or downloads, review the real Chromium and Firefox workflows
at both 1440 and 375 pixels using the commands in the README.

Source corrections need an edition, printed page or plate, and the specific
reading. Preserve discrepancies in the manuscript and differences between
editions. A new explanation should help someone perform or inspect an operation;
extra prose, invented monument reconstructions and unsupported historical claims
are not substitutes for that.

Keep the code free of runtime dependencies, trackers and external font requests.
Include provenance and rights for any additional source image. Recheck standalone
HTML and print output when changing diagrams or reading content. The publication
workflow preserves older hashed assets for readers with cached entry pages.
